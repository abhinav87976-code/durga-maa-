# 🔱 Maa Durga - Mahishasura Mardini Live Python Art 🦁

A dynamic Python script utilizing **Turtle Graphics** and **OpenCV** to render a live, stroke-by-stroke sketch animation of Maa Durga slaying Mahishasura, finished with a festive "Shubh Navratri" artwork at the top.

---

## 🚀 Quick Run (All-in-One)

Copy and run everything in one go:


# 1. Clone the repo
```
git clone [https://github.com/Gracyclub/Durga-Maa-Python-sketch.git]
```

cd Durga-Maa-Mahishasura-Mardini-Python-Art

# 2. Install dependencies & Run
```
pip install opencv-python numpy
python durga.py
```
